這是一份專為**商用計算機 App** 設計的功能需求規格書（PRD, Product Requirements Document）。商用計算機與一般工程或基本計算機的最大差別在於：**精準度（稅率、四捨五入模式）、歷史記錄稽核、商業利潤計算，以及多幣別與大數據格式化**。

## **📋 商用計算機 App \- 功能需求規劃**

### **一、 核心計算與商業模式（Core Calculation & Business Features）**

| 模組名稱 | 功能項目 | 說明與詳細需求 |
| :---- | :---- | :---- |
| **基本四則與商業運算** | 標準運算 | 支援加、減、乘、加總（$+$）、扣除（$-$）。 |
|  | **GT (Grand Total) 總計功能** | 自動累積所有乘除計算的總和，方便盤點、清點多筆總金額。 |
|  | \*\*MU (Markup / 利潤率計算) \*\* | 專為零售業設計：輸入成本與利潤百分比，一鍵計算出定價（售價），反之亦然。 |
| **稅率計算（Tax）** | 含稅 / 未稅一鍵切換 | 設定固定稅率（如營業稅 5%、消費稅 8%/10% 等）。提供 Tax+（加稅）與 Tax-（扣稅）獨立實體或虛擬按鍵。 |
| **精確度與捨入控制** | 小數位數鎖定 (F, 5/4, CUT, UP) | 模擬專業桌上型商用計算機的捨入模式： • **F**：浮動小數點。 • **CUT**：無條件捨去。 • **UP**：無條件進位。 • **5/4**：四捨五入。 |
|  | 小數位數設定 (Decimal Selector) | 可鎖定小數點後 0、2、3、4 位數，避免會計計算時產生誤差。 |

### **二、 商業實用與稽核工具（Business Audit & Workflow）**

* **歷史記錄與紙帶檢視（Paper Tape History）**  
  * **滾動式紙帶**：像傳統印表機計算機一樣，完整記錄每一步計算過程（包含稅率計算、MU計算、刪除的步驟）。  
  * **備註與標籤**：允許使用者在歷史記錄中的特定行或整筆計算加上文字標籤（例如：「3月辦公用品」、「客戶A報價」）。  
  * **匯出與分享**：支援將計算紙帶記錄匯出為 **PDF**、**Excel (CSV)** 或文字檔，方便直接透過 Line、Email 傳給主管或客戶做為憑證。  
* **多欄位 / 記憶體擴充（Advanced Memory）**  
  * 傳統的 M+, M-, MRC 外，支援**多組獨立記憶體**（M1, M2, M3），讓會計人員可以同時處理多張發票或帳單的暫存數字。

### **三、 使用者體驗與介面設計（UI / UX Requirements）**

* **擬真與現代雙模式介面**：  
  * **經典商用模式**：仿製經典雙向電力/太陽能桌上型計算機（如卡西歐、佳能大按鍵風格），鍵盤配置符合會計師、店員盲打習慣。  
  * **現代簡約模式**：符合 iOS / Android 設計規範的俐落商務風格，支援暗色模式（Dark Mode）。  
* **震動與聲音回饋（Haptic Feedback）**：  
  * 提供逼真的機械按鍵敲擊音效與觸覺回饋（可手動開關），確保在快速盲打時不會漏按。  
* **數字格式化（Number Formatting）**：  
  * 自動支援千分位逗號分隔符（例如：$1,234,567.89$），並可切換不同國家的數字分位習慣（如印度計數系統或國際標準）。

### **四、 附加加值功能（Value-Added Features for Business）**

* **單位與匯率換算（Currency & Unit Converter）**：  
  * 內建即時外匯匯率換算（需連網更新），方便進出口貿易、代購業快速換算成本。  
  * 常用商用單位換算（如才數、重量、長度、容積）。  
* **分帳與小費計算（Quick Split）**：  
  * 餐飲或服務業適用：快速計算多人聚餐或團體消費的分攤金額與小費比例。

### **五、 非功能性需求（Non-Functional Requirements）**

* **效能與穩定度**：計算必須達到絕對精確（避免浮點數誤差，建議後端採用精確十進位運算庫如 Decimal.js 或原生高精度套件）。  
* **資料安全**：所有計算記錄與自定義標籤預設僅儲存在本機（Local Storage），若有雲端同步需求需符合企業資安規範。  
* **離線優先（Offline-First）**：即使在沒有網路的地下室、展場或倉庫，核心計算與基本功能皆可正常運作。
