## 句子翻譯範例

### 提示訊息

```
原文：Are you sure you want to delete this item?
譯文：確定要刪除這個項目嗎？

原文：Changes saved successfully.
譯文：變更已儲存。

原文：Please enter a valid email address.
譯文：請輸入有效的電子郵件地址。

原文：This field is required.
譯文：這是必填欄位。

原文：Password must be at least 8 characters.
譯文：密碼必須至少 8 個字元。
```

### 錯誤訊息

```
原文：An error occurred. Please try again later.
譯文：發生錯誤，請稍後再試。

原文：File upload failed.
譯文：檔案上傳失敗。

原文：Invalid username or password.
譯文：使用者名稱或密碼無效。

原文：You do not have permission to access this page.
譯文：你沒有權限存取這個頁面。

原文：Session expired. Please log in again.
譯文：工作階段已過期，請重新登入。
```

### 成功訊息

```
原文：Your account has been created.
譯文：你的帳號已建立。

原文：Post published.
譯文：文章已發佈。

原文：Settings updated.
譯文：設定已更新。

原文：File uploaded successfully.
譯文：檔案上傳成功。
```

### 確認對話框

```
原文：Delete this item permanently?
譯文：要永久刪除這個項目嗎？

原文：Discard unsaved changes?
譯文：要捨棄未儲存的變更嗎？

原文：Log out of your account?
譯文：要登出你的帳號嗎？
```

## PO 檔案翻譯範例

### 輸入

```po
msgid "Settings"
msgstr ""

msgid "Save Changes"
msgstr ""

msgid "Are you sure you want to delete this item?"
msgstr ""
```

### 輸出

```po
msgid "Settings"
msgstr "設定"

msgid "Save Changes"
msgstr "儲存變更"

msgid "Are you sure you want to delete this item?"
msgstr "確定要刪除這個項目嗎？"
```
