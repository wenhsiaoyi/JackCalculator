# 台灣正體中文翻譯風格指南

## 基本原則

### 1. 準確性
- 忠實傳達原文意思
- 不增刪原文內容
- 專有名詞使用標準譯法

### 2. 流暢性
- 符合中文語法習慣
- 避免過度直譯
- 句子通順易讀

### 3. 一致性
- 同一詞彙使用相同翻譯
- 遵循詞彙表標準
- 風格統一

---

## 標點符號

### 使用全形標點

| 符號 | 全形 | 用法 |
|------|------|------|
| 逗號 | ， | 句中停頓 |
| 句號 | 。 | 句子結束 |
| 頓號 | 、 | 並列詞語 |
| 分號 | ； | 分句停頓 |
| 冒號 | ： | 說明、引出 |
| 問號 | ？ | 疑問句 |
| 驚嘆號 | ！ | 感嘆句 |
| 引號 | 「」 | 引用、強調 |
| 雙引號 | 『』 | 引號內再引用 |
| 括號 | （） | 補充說明 |
| 書名號 | 《》 | 書名、刊物 |
| 破折號 | —— | 解釋、轉折 |
| 省略號 | …… | 省略、未完 |

### 半形標點使用情況

- 英數字旁邊可用半形
- 網址、程式碼中使用半形
- 數學運算符號

## 空格規則

### 中英文之間加空格

✓ 正確：
- 請使用 WordPress 5.0 以上版本
- 這是一個 API 請求
- 按下 Enter 鍵

✗ 錯誤：
- 請使用WordPress 5.0以上版本
- 這是一個API請求

### 中文與數字之間加空格

✓ 正確：
- 共有 10 個檔案
- 版本 2.0 已發布

✗ 錯誤：
- 共有10個檔案
- 版本2.0已發布

### 全形標點與文字之間不加空格

✓ 正確：
- 這是一個測試，請確認。
- 選項包括：A、B、C

✗ 錯誤：
- 這是一個測試 ， 請確認 。

## 數字格式

### 阿拉伯數字

適用於：
- 版本號：2.0、5.9.1
- 日期：2026 年 2 月 5 日
- 時間：下午 3:00
- 金額：NT$ 1,000
- 百分比：50%
- 數量：10 個

### 中文數字

適用於：
- 成語：一舉兩得
- 約數：十幾個、幾百人
- 序數：第一步、第二章

### 稱「文」不稱「語」

| 英文 | 台灣用法 | 避免用法 |
|------|----------|----------|
| English | 英文 | 英語 |
| Chinese | 中文 | 漢語、華語 |
| Japanese | 日文 | 日語 |
| Korean | 韓文 | 韓語 |
| French | 法文 | 法語 |
| German | 德文 | 德語 |
| Spanish | 西班牙文 | 西班牙語 |

## 專有名詞

### 保留英文

- 軟體/服務名稱：WordPress、Google、Facebook
- 程式語言：JavaScript、Python、PHP
- 技術規格：HTML、CSS、JSON、API
- 品牌名稱：Apple、Microsoft、Adobe

### 翻譯為中文

- 一般術語：使用詞彙表標準譯法
- 介面元素：按鈕、選單、對話框
- 操作動作：儲存、刪除、上傳

---

## 語氣

### 軟體介面用語

- 使用禮貌但簡潔的語氣
- 避免過於口語化
- 避免命令式語氣

✓ 正確：
- 請選取一個選項。
- 確定要刪除嗎？
- 設定已儲存。

✗ 錯誤：
- 選一個！
- 你確定嗎？？
- 好了！存好了！

### 錯誤訊息

- 說明問題
- 提供解決方案
- 避免責備使用者

✓ 正確：
- 無法連線到伺服器，請檢查網路連線後再試一次。
- 檔案格式不支援，請上傳 JPG、PNG 或 GIF 格式的圖片。

✗ 錯誤：
- 連線失敗！
- 檔案錯誤。

## 首字大小寫

### 原文小寫開頭時，譯文勿以大寫英文起頭

當原文以 ASCII 小寫字母開頭（常見於句子片段，如 `an experiment…`、`by default…`），
譯文若以大寫英文單字起頭，Loco Translate 會警告「missing the initial lowercase」。
應改以中文字或符號開頭：

✓ 正確：
- `an experiment by Automattic` → 由 Automattic 進行的實驗
- `by default, posts are public` → 預設情況下，文章為公開

✗ 錯誤：
- `an experiment by Automattic` → `Automattic 進行的實驗`（以大寫英文起頭）

> 可用 `python scripts/po.py validate <file.po>` 自動偵測此問題（code: `initial-lowercase`）。

## 複數處理

### 中文不需要複數標記

✓ 正確：
- 選取檔案（不是「選取檔案們」）
- 所有使用者（不是「所有使用者們」）
- 刪除項目（不是「刪除項目們」）

### 需要強調數量時

- 1 個檔案
- 2 位使用者
- 多個項目
